# 散场以后，第九场

本案是一宗围绕一笔公共放映补助的虚构案件。案件入口是案件列表；完整背景从卡片或庭内卷宗展开。案件包包含全部角色、公开事实、两造材料和证人私有知识，可以独立导出、导入。以下含作者剧透。

## 两个有不同答案的问题

大厅停映、程遥签报、剧院收款均无争议。余片是否按约向原票观众开放，以及程遥递交申领时是否知道申领不实，分别影响客观不实与主观明知。即便剧院履约有缺陷，也可能在后一项上存在合理怀疑。辩方可以承认第一组已知事实，集中攻一项待证要件。

|材料|接续的证明环节|留下的追问|
|---|---|---|
|申领页和付款联|完成栏直接决定九号的款项|签字时发生过什么|
|停映单|停机消息经程遥本人签收|这张单管哪间屋|
|票窗领班|退票、去电、报整场的原话|领班可见哪扇门，零钱凭条覆盖哪个时段|
|用途簿|第二房登记为内部校片|用途与交回时间何时落笔|
|值守员|程遥亲自交回西口的止步牌|预订用途能否证明实际用途，东侧是否另有通道|
|片尾纸带|字幕余片确实放完|谁有机会看|
|蓝夹票根|五张可核对原售票流水|是否只是成叠送来的小头|
|持票人|四〇六大头与东廊小头合上；亲历指路、入场及片尾|她能代表多少人|
|交接笺|有关接续与原票的报告在签字前已存在|压痕不能证明收件人阅读|
|收发员|读出数字的原话和递纸先后补上这一步|经手人能证明收到消息，无法证明主任相信什么|

作者设定为西口退票和东廊接续同时发生。领班离窗后替人补勾，值守员下午预填用途却没有复验，观众带了没有票的同行者，收发员省略了签收。各人有单独的利害，只知道自己经手的那一截。公开小传可以解释性格，具体隐情留在证人私有知识中。检方证人能诚实完成主询问而不自动揭开这些事。辩方必须寻找观察范围、落笔时刻或物件来历等具体问题。

## 角色与内容加载

案件目录支持完整的 bundle.yaml，与原有共享角色的 case.yaml 并列。新案采用十二份具名小传组成候选池；姓名、职业、年龄、性格与经历共同抽取，按种子无放回选任并分配席位。旧案件继续使用原来的加权候选池。证人小传在对应出庭记录内展开，十二名陪审员、法官、检察官与被告的公开资料在左侧卷宗查看。公开背景和每份小传分别用汉字数量校验，人物不计姓名标签和职业栏，证人秘密不计入篇幅。

## 可玩性验收

在线模式交由各席依据本庭公开、获准使用的材料判断。单个证人只获得自己的私有知识。离线演示的补充问答按案件包的提示词匹配，裁决按获采材料和对应证人的实际公开回答运行。

- 控方五项均采纳，辩方保留陈述、无实质质询且不举证，应得到有罪。
- 单独呈交小机纸带与交接笺，可以证明机器动过和消息存在，还不足以改变离线裁决。
- 纸带、原票和持票人的回答接起公开放映，或交接笺与经手人接起签字前获知，均能在一个必要要件上形成合理怀疑。
- 只揭出两位控方证人的观察与登记缺口，也会造成分歧；止步牌、停映单和程遥亲口指示仍有分量。演示十轮不能一致时宣告僵局。

测试通过真实庭审引擎完成上述路径。离线投票是案件脚本，在线模型的票数和轮次随实际庭审变化。
