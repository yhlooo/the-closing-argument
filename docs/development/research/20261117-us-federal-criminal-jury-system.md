## 1. 制度概览与术语

美国联邦刑事程序中的“陪审团”实际上包含两种不同机构：

| 项目 | 大陪审团（grand jury） | 刑事审判陪审团（petit / trial jury） |
| --- | --- | --- |
| 核心任务 | 调查涉嫌犯罪，判断是否具有提出正式刑事指控的充分根据 | 判断检方是否依法证明被告犯有所指控的罪 |
| 所处阶段 | 调查与起诉阶段，可在逮捕前或后进行 | 被告不认罪、案件进入陪审团审判之后 |
| 人数 | 16—23 人 | 原则上 12 人，存在规则规定的例外 |
| 证明门槛 | 相当理由（probable cause） | 排除合理怀疑（beyond a reasonable doubt） |
| 作出决定的票数 | 至少 12 人同意提出起诉，不要求全体一致 | 裁决必须一致，包括有罪与无罪 |
| 是否由控辩双方对抗举证 | 通常由检方提供证据，没有完整的控辩对抗程序 | 有控辩双方举证、质证和辩论 |
| 法官是否主持证据听取 | 通常不在调查室内主持；法院处理法律问题并提供程序监督 | 法官主持庭审，裁决法律及证据问题 |
| 公开性 | 原则上不公开，适用专门保密制度 | 庭审原则上公开，评议不公开 |
| 工作单位 | 在任期内可以处理多个调查或案件 | 围绕所审理的特定案件作出裁决 |

依据：[Rule 6、Rule 23、Rule 31][R03]；[联邦法院对两类陪审团的说明][R26]。

“大”“小”主要是历史上的人数区分，**并不代表上下级关系**。审判陪审团不审查大陪审团是否“判对了”，因为大陪审团根本没有作出有罪裁决。

联邦刑事程序的主要路径可以表示为：

```text
联邦犯罪调查
    ├─ 必须经大陪审团的案件 → 大陪审团决定是否起诉 → indictment
    └─ 法律允许的其他路径   → 检察官起诉书 information 等
                                  ↓
                         提审、答辩、审前程序
                    ┌─────────────┴─────────────┐
                法院接受认罪                 被告不认罪
                    ↓                           ↓
                通常直接量刑         有陪审团权且未有效放弃？
                                      ├─ 是 → 陪审团审判
                                      └─ 否 → 法官独任审判
                                                 ↓
                                    无罪 / 有罪 / 部分裁决 / 僵局
                                                 ↓
                                   如定罪：裁决后动议、量刑、上诉
```

这张图是程序概括。大陪审团调查、逮捕、初次出庭等步骤的先后并非所有案件都相同；认罪也不必然意味着此前没有经过大陪审团。[Rules 3—11、23、31、32][R03]

## 2. 宪法与法律基础

### 2.1 三组主要宪法保障

**第一，《宪法》第三条第二款第三项。** 除弹劾案件外，犯罪审判应由陪审团进行，并规定犯罪发生州与审判地点的关系。这是原始宪法对刑事陪审团的直接安排。[《宪法》第三条][R01]

**第二，第五修正案。** 对死刑罪或其他“重大犯罪”（infamous crime），原则上要求大陪审团提出起诉，并规定不得就同一犯罪使人两次陷于刑事危险的保障。修正案中的军事例外也说明，普通联邦刑事程序不能直接套用到所有国家惩罚活动。[第五修正案][R02]

**第三，第六修正案。** 被告享有迅速、公开、由公正陪审团审理的权利。陪审团须来自犯罪发生的州及依法预先划定的司法区。第六修正案还保障知悉指控、对质、强制传唤有利证人与律师协助，这些权利共同构成陪审团判断事实的程序环境。[第六修正案][R02]

第七修正案主要涉及民事普通法诉讼中的陪审团保障，不能用它代替刑事程序中的第五、第六修正案依据。[第七修正案][R02]

### 2.2 从宪法原则到可操作程序

| 规范层次 | 主要内容 | 阅读时应注意什么 |
| --- | --- | --- |
| 宪法及最高法院解释 | 哪些案件有陪审团权、公正性、一致裁决、不得重复追诉等 | 是制度的上位约束 |
| 《陪审员选任与服务法》及 28 U.S.C. §§ 1861—1878 | 随机选任、代表性、资格、豁免、异议、补助及就业保护等 | 同时保护诉讼当事人与有资格服务的公民 |
| 《联邦刑事诉讼规则》 | 大陪审团、人数、放弃权利、选任、替补、指示、裁决等 | 核对实际生效版本，不能把委员会草案当作法律 |
| 《联邦证据规则》 | 证据是否可被陪审团听取，裁决后能否用陪审员证言质疑裁决等 | 大陪审团调查、普通庭审、量刑的适用范围不同 |
| 特别成文法 | 例如联邦死刑量刑听证、特别大陪审团 | 可能规定不同于普通程序的专门规则 |
| 地区法院选任计划、地方法规及个案命令 | 名册来源、通知、服务安排、保密措施等 | 在上位规范允许的范围内存在地方差异 |
| 巡回区示范陪审团指示 | 将犯罪构成、证明标准、评议要求转化为陪审员可理解的语言 | 是重要参考，不能一概视为全国强制文本 |

## 3. 制度试图解决的问题与设计原则

本节是对制度结构的分析；相应的法律规则及历史依据在后文展开。

### 3.1 在国家追诉与个人自由之间设置公民判断

联邦检察官代表国家提出指控，职业法官掌握程序和法律解释权，但在有陪审团权且未被有效放弃的案件中，认定犯罪成立还需要公民陪审团的判断。

这种权力配置使调查、起诉、法律裁判与有罪事实认定不完全集中在同一机构。大陪审团在起诉端设置审查，审判陪审团在定罪端设置另一道、证明门槛明显更高的审查。[Duncan v. Louisiana, 391 U.S. 145, 155—156 (1968)][C06]；[Rules 6、23、31][R03]

这是一项结构性制约，不能据此推定每个陪审团在现实中都能够有效抵抗检方，也不能认为公民参与本身足以保证正确结论。

### 3.2 代表性与公正性是两项不同要求

**代表性**首先约束陪审员来源和候选人群体，要求从社区的公平横截面中随机选任，避免制度性排除某个可识别群体。

**公正性**关注进入具体案件的个人是否能够依据证据和法律判断，而不受利害关系或偏见支配。

因此，具备统计代表性的候选人池仍可能产生存在偏见的个别候选人；一组自认为公正的人，也可能来自违法排除某群体的名册。两层保障都不可省略。[28 U.S.C. § 1861][U1861]、[§ 1862][U1862]、[§ 1863][U1863]；[Taylor v. Louisiana, 419 U.S. 522 (1975)][C10]；[Duren v. Missouri, 439 U.S. 357 (1979)][C11]

这也解释了为什么法律不保证最终 12 人按人口比例配置，更不要求其与被告具有相同种族、职业或社会身份。

### 3.3 专业法律控制与公民事实判断相结合

法官负责解释法律、控制证据和程序；陪审团负责评估证据、判断可信度，并根据法官的法律指示作出裁决。两者共同构成裁判过程。

这种分工既需要法官把法律准确地转化为指示，也需要限制法官直接替代陪审团认定有罪。陪审员则有义务遵循法律指示，不能仅凭个人政策立场改写犯罪构成。[Sparf and Hansen v. United States, 156 U.S. 51, 102—106 (1895)][C01]

### 3.4 对错误定罪与错误放过采取不对称处理

检方对犯罪构成要件承担排除合理怀疑的证明责任；有罪裁决须一致；证据不足时法院能够作出无罪判决；已经有效作出的陪审团无罪裁决受到强力终局性保护。

这些规则共同体现一种价值选择：国家应承担证明犯罪的风险，不能把“无法证明无罪”的风险转给被告。[In re Winship, 397 U.S. 358, 363—364 (1970)][C08]；[Rule 29、Rule 31][R03]；[McElrath v. Georgia, 601 U.S. 87 (2024)][R22]

### 3.5 公开审判与私人评议各自承担不同功能

公开庭审使证据提出、律师辩论和法官裁判受到外部监督；私人评议保护陪审员表达与讨论，减少即时舆论、威胁和外部干涉。

评议保护并非绝对：外部有害信息、外界不当影响，以及符合宪法例外标准的严重种族偏见，可能使法院有必要调查裁决形成过程。[第六修正案][R02]；[FRE 606(b)][R04]；[Peña-Rodriguez v. Colorado, 580 U.S. 206 (2017)][R23]

### 3.6 通过有边界的程序弹性控制成本

替补陪审员、特定条件下由 11 人继续评议、对不同罪项分别作出裁决、有效放弃陪审团审判等，都能降低程序因个别故障完全重来的成本。

这些弹性同时受到书面约定、法院批准、正当理由、重新评议或一致裁决等条件约束。它们是在既定权利结构内处理故障的机制。[Rules 23、24、31][R03]

## 4. 什么案件有权要求陪审团

### 4.1 “刑事案件”不等于每案都有宪法上的陪审团审判权

最高法院区分严重犯罪与轻微违法（petty offenses）：

- **单一罪名的法定最高监禁刑超过 6 个月**，足以触发第六修正案的陪审团审判权。
- **法定最高监禁刑为 6 个月或以下**，推定属于轻微违法；但不是绝对排除，还要考虑附加法定处罚是否严重到表明立法机关把它当作严重犯罪。
- 判断重点是法律授权的最高处罚，而非检察官口头预计的刑期或法官最终实际判了多久。

依据：[Baldwin v. New York, 399 U.S. 66 (1970)][C07]；[Blanton v. City of North Las Vegas, 489 U.S. 538 (1989)][C17]。

**重罪／轻罪分类与陪审团权不是同一条分界线。** 例如，最高可判一年监禁的某些轻罪仍属于有陪审团审判权的严重犯罪。不能把“只有重罪才有陪审团”当作联邦规则。

### 4.2 大陪审团起诉权与审判陪审团权应分别判断

Rule 7(a) 原则上要求：可能判处死刑，或者监禁超过一年的犯罪，须通过 indictment 起诉，后者存在规则允许的放弃路径；刑事藐视法庭案件不适用该条的一般起诉要求。较轻犯罪可以通过 information 等方式起诉。

因此，一个最高刑为一年的案件可能有审判陪审团权，却不要求大陪审团起诉。这是两个不同阶段、不同门槛的权利。[Rule 7][R03]

### 4.3 被告能否选择由法官独任审判

有陪审团审判权时，Rule 23(a) 要求同时满足：

1. 被告书面放弃陪审团审判；
2. 检方同意；
3. 法院批准。

所以，被告通常不能单方面宣布“我更信任法官，请不要陪审团”。最高法院在 *Singer* 案中认可了要求检方同意的制度。[Rule 23(a)][R03]；[Singer v. United States, 380 U.S. 24 (1965)][C03]

认罪是另一种程序选择。法院接受认罪前，须核查被告理解相关权利及放弃的后果、认罪具有自愿性，并满足规则要求的事实基础等条件。不能把认罪与 Rule 23 下仍然进行的独任审判混为一谈。[Rule 11][R03]

## 5. 大陪审团：调查与起诉审查

### 5.1 它回答的是“能否提出指控”，而非“是否已经证明有罪”

联邦大陪审团具有调查功能，可以听取证人、审查文件，并通过法律程序取得证据。检察官通常向其介绍适用法律、组织证据并提出拟议指控。

大陪审团需要判断是否有相当理由相信发生了联邦犯罪，且被调查人实施了该犯罪。通过后形成 indictment，正式列出指控。indictment 本身不是证明被告有罪的证据。[大陪审员手册的任务、调查与证明门槛部分][R12]

大陪审团既可以帮助国家调查犯罪，也可以拒绝检方提出的指控。这两种功能经常分别被描述为“剑”与“盾”；其现实效果需要结合程序结构评估。

### 5.2 人数、法定人数、票数和任期

- 组成时为 **16—23 人**。
- 执行工作所需法定人数通常为 **16 人**。
- 提出一项 indictment 须至少 **12 名陪审员同意**。这里采用固定最低赞成票数，不是随到场人数变化的简单多数制，也不要求全体一致。
- 普通大陪审团原则上任期不超过 **18 个月**；法院为公共利益可以延长，延长期不超过 **6 个月**。
- 依 18 U.S.C. § 3331 设立的特别大陪审团适用专门任期规定，不能一律套用普通大陪审团的“18＋6 个月”。

依据：[Rule 6(a)、(f)、(g)][R03]；[手册的 Quorum 部分][R12]；[18 U.S.C. § 3331][R07]。

### 5.3 谁可以在场

听取证据时，规则允许在场的通常是政府律师、正在受询问的证人、必要的口译人员以及速记或录音人员。

被调查人没有参加全部调查、持续观察全部证据或在调查室内由律师进行交叉询问的一般权利。出庭作证的证人也不因此丧失反对强迫自证其罪等适用保障；大陪审团的调查权并非可以排除所有宪法限制。

**进入评议与表决后，检察官也必须退出。** 仅陪审员，以及规则特别允许帮助听觉或言语障碍陪审员的口译人员，可以在场。[Rule 6(d)][R03]；[手册的证人询问与调查部分][R12]

### 5.4 为什么证据规则与普通庭审不同

FRE 1101(d)(2) 将大陪审团程序排除在普通证据规则的一般适用范围之外，但特权规则仍有其适用地位。因此，庭审中可能被排除的传闻，不当然不能由大陪审团考虑。

大陪审团通常也不是一场提前进行的完整无罪证据审判。最高法院在 *United States v. Williams* 中否定了法院仅依一般监督权，要求检方在大陪审团面前呈交重要无罪证据的做法。这个结论有特定范围，不能扩张成“检察官可以违法误导大陪审团”。[FRE 1101(c)、(d)][R04]；[United States v. Williams, 504 U.S. 36, 51—55 (1992)][C18]

### 5.5 保密制度保护什么

Rule 6(e) 对大陪审员、检察官、记录人员等设定保密义务，并规定法定披露例外。保密可以保护调查、证人的安全及配合意愿，也能避免尚未受到正式起诉的人因调查曝光承受无端名誉损害。[Rule 6(e)][R03]；[手册的 Secrecy 部分][R12]

两项边界尤其重要：

- 保密不是“没有记录”。除评议和投票外，程序原则上应当记录。
- 证人并不因为作证而自动成为 Rule 6(e)(2)(B) 列举的保密义务人；其他法律或合法命令是否限制其披露，需要另外判断。

### 5.6 拒绝起诉不是无罪裁决

大陪审团拒绝提出起诉常被称为 no bill。它表示本次没有形成所需的起诉决定，并未在一次有罪审判中判被调查人无罪。因此，不能仅凭这次拒绝起诉就主张陪审团无罪裁决所具有的不得重复追诉效果。后续重新呈交等问题仍受适用法律及程序约束。[Rule 6(f)][R03]；[大陪审员手册对拒绝起诉效力的说明][R12]

**制度分析：** 大陪审团的独立表决具有法律意义，但它通常在由检方组织证据、没有完整辩方对抗的环境中工作。这会形成明显的信息不对称；单凭“由公民组成”无法判断其实际审查强度。

<a id="s6"></a>
## 6. 陪审员从哪里来：名册、随机抽取与资格

### 6.1 从社区到候选人池的多阶段过程

联邦地区法院必须制定书面随机选任计划，并经过法定审查。常见过程是：

```text
选民登记名册或实际投票名册
  ＋ 为实现公平代表性所必需的其他名册
                    ↓ 随机抽取
主陪审员名册（master jury wheel）
                    ↓ 资格调查表、法定审查
合格陪审员名册（qualified jury wheel）
                    ↓ 随机抽取、发出传票
到庭候选人群体（panel / venire）
                    ↓ 个案询问与依法排除
实际参加该案的陪审团与替补陪审员
```

“wheel”是法定术语，不要求法院仍使用机械抽签轮。依法发挥相同功能的装置或系统也可以使用。[28 U.S.C. §§ 1863—1866][R05]；[联邦法院选任流程说明][R09]

选民名册是法定主要来源，但不能机械地认为“只要用了选民名册就已经公平”。在实现法律保障所必需时，计划应增加其他来源。各地具体使用的补充名册可能不同。

### 6.2 基本资格

根据 28 U.S.C. § 1865，基本要求包括：

| 项目 | 法律要求的主要内容 |
| --- | --- |
| 公民身份、年龄、居住 | 美国公民，年满 18 岁，在该司法区居住满一年 |
| 语言能力 | 具有依法完成资格调查表所需的英语阅读、书写、理解能力，并能够说英语 |
| 履职能力 | 不存在使本人无法适当履行陪审义务的精神或身体状况；不能简化成“有残障就不合格” |
| 特定刑事状态 | 对可能判处超过一年监禁的犯罪存在待决指控，或有相关定罪且公民权未恢复，可能不符合资格 |

这些要求没有设定法学学历、律师资格或专业证据知识门槛。[28 U.S.C. § 1865][U1865]；[联邦法院资格说明][R10]

### 6.3 不合格、法定豁免、个别免除与延期应当区分

不符合资格的人与具有资格但因职业或个别困难不服务的人，法律地位不同。

- 法律规定现役军人、消防或警察部门成员、积极履行职责的特定公职人员等豁免类别；“公职人员”须依相关法定定义理解，不能泛指所有政府雇员。
- 地方法院计划可以在法定范围内规定依申请免除服务的类别。
- 不当困难或极度不便，可以成为个别免除或延期的依据，但不意味着只要工作繁忙就能够自行拒绝传票。

依据：[28 U.S.C. § 1863(b)(5)—(6)][U1863]、[§ 1866(c)][U1866]；[§ 1869 对相关术语的定义][U1869]。

### 6.4 代表性不等于最终陪审团的比例配额

公平横截面要求主要作用于选任来源与候选人形成过程。它不保证每个具体陪审团都包含某个族群成员，也不要求每个陪审团复制社区的人口统计。

*Duren* 案确立的初步证明框架主要包括：被排除者属于社区中可识别的群体；该群体在候选人群体中的代表不足达到不公平、不合理程度；不足源于选任过程中的系统性排除。由此提出初步证明后，还需分析政府是否有足以支持该安排的理由。[Duren, 439 U.S. 357, 364—368][C11]

对严重违反联邦选任法律的程序，法律还规定了提出异议、查阅相关名册材料等机制，并设有严格时限。它不是必须等到有罪裁决后才能提出的问题。[28 U.S.C. § 1867][U1867]

### 6.5 补助与就业保护也是参与机制的一部分

联邦陪审员通常每天领取 **50 美元**服务费；符合条件时，审判陪审员在服务超过 10 天后、大陪审员在服务超过 45 天后，可能获得最高每天 60 美元的较高费用。差旅等报销依规定处理，部分人员另有例外。

联邦法保护受该条保障的正式雇员（permanent employees），使其免受因联邦陪审服务而发生的解雇、威胁或胁迫，但不一般性要求雇主继续支付工资。[28 U.S.C. § 1871][U1871]、[§ 1875][U1875]；[联邦法院服务费说明][R11]

**制度分析：** 如果服务造成的收入、照护或交通成本主要由个人承担，能够实际到庭的人群就可能发生偏移。因此，名册的形式随机性与实际参与的可及性需要分别观察。

<a id="s7"></a>
## 7. 如何组成个案的审判陪审团

### 7.1 Voir dire：识别能否公正履职

voir dire 是对候选陪审员的询问，常涉及与当事人、证人或案件的关系，既有信息，相关经历，以及是否能够遵守无罪推定、证明责任和法院指示。

Rule 24 允许法官自行询问，也允许律师询问。由法官询问时，律师仍有规则规定的补充问题参与方式，但问题是否适当由法院控制。因此，美国联邦选任并不总是影视作品中律师逐人自由盘问的形式。[Rule 24(a)][R03]

询问的目标是判断能否公正审理。仅仅听说过案件，与已经形成无法放下的定见，是不同问题；是否需要排除，应结合具体回答和适用标准判断。

### 7.2 有因排除与无因排除

**有因排除（challenge for cause）**要求提出足以说明候选人不适合审理该案的原因，例如利益关系或无法克服的偏见，由法院裁定。它不适用 Rule 24(b) 对无因排除规定的固定名额。

**无因排除（peremptory challenge）**通常不必先证明达到有因排除标准，但次数有限，且不能基于禁止的歧视理由行使。“无因”并不表示遇到歧视异议时永远无需解释。[Rule 24][R03]；[28 U.S.C. § 1866(c)][U1866]

### 7.3 联邦刑事案件的无因排除名额

| 案件类别 | 检方 | 辩方 | 条件与说明 |
| --- | --- | --- | --- |
| 检方寻求死刑的案件 | 20 次 | 20 次 | 以检方是否寻求死刑为规则条件 |
| 其他最高可判超过一年监禁的案件 | 6 次 | 10 次 | 多名被告通常共同使用辩方名额；法院可依规则增加或安排分别、共同行使 |
| 最高刑为一年或以下监禁、罚金或兼有的案件 | 3 次 | 3 次 | 本表不意味着所有此类案件都有陪审团审判权 |

如果另选替补陪审员，双方还有专门用于替补候选人的额外名额：1—2 名替补对应每方 1 次，3—4 名对应每方 2 次，5—6 名对应每方 3 次。这些额外名额只能用于替补候选人。[Rule 24(b)、(c)(4)][R03]

### 7.4 Batson：无因排除也受到反歧视约束

围绕涉嫌种族歧视的无因排除，通常使用三阶段审查：

1. 异议方提出足以产生歧视推断的初步事实；
2. 行使排除的一方提出表面上种族中立的解释；
3. 法院结合情况判断是否存在故意歧视，不能止于机械接受一个中立措辞。

*Batson* 约束检方以种族为由排除候选人。后续判例明确，被告不必与被排除陪审员属于同一种族，辩方也不能进行种族歧视性排除；*J.E.B.* 则禁止以性别刻板印象为由行使无因排除。[Batson v. Kentucky, 476 U.S. 79 (1986)][C12]；[Powers v. Ohio, 499 U.S. 400 (1991)][C22]；[Georgia v. McCollum, 505 U.S. 42 (1992)][C21]；[J.E.B. v. Alabama ex rel. T.B., 511 U.S. 127 (1994)][C13]

这类规则既保障被告公正受审，也保护公民不因歧视被剥夺参与司法的机会。由于排除理由可能具有策略性、也可能掩盖偏见，审查实际动机是该机制最困难的部分之一。

### 7.5 正式陪审员与替补陪审员

联邦刑事审判陪审团原则上有 **12 名正式成员**，并可选任最多 **6 名替补**。替补具有相同资格，以相同方式选任、宣誓，在依法替换前不能作为额外正式成员参加评议。

庭审中正式陪审员不能继续履职时，替补按选任顺序替换。法院可以在评议开始后保留替补，但必须使其与案件讨论隔离；若在评议开始后替换正式成员，法院必须指示新组成的陪审团**从头开始评议**。[Rule 24(c)][R03]

Rule 23(b) 另允许经法院批准的书面协议采用少于 12 人的陪审团；评议开始后，如有正当理由需要解除一名陪审员，法院可以在没有双方协议的情况下准许剩余 11 人作出裁决。这不是允许因少数陪审员持不同意见就将其排除。[Rule 23(b)][R03]

## 8. 庭审中的角色分工与运行流程

### 8.1 谁负责什么

| 参与者 | 主要职责 | 权限边界 |
| --- | --- | --- |
| 法官 | 主持程序、决定法律问题、裁定证据、指示陪审团、处理动议并通常负责量刑 | 不得仅因自认证据充分就替陪审团宣布被告有罪 |
| 检察官 | 代表联邦政府提出指控、举证、询问与辩论 | 对犯罪构成要件承担排除合理怀疑的证明责任 |
| 辩护方 | 检验检方证据、交叉询问、提出辩护证据和法律主张 | 通常没有证明被告无罪的一般责任；特定积极抗辩可能另有举证规则 |
| 陪审团 | 判断证据与证人可信度，认定事实，依法形成裁决 | 应遵守法官法律指示，仅以可依法考虑的证据裁判 |
| 证人及专家 | 就事实或适当专业问题提供证言，接受询问 | 证言是受审查的证据，不等于其可以替陪审团作出裁决 |

依据：[刑事诉讼规则 Rules 26、29、30、32][R03]；[证据规则 Rules 104、702][R04]；[Sparf][C01]；[Winship][C08]。

### 8.2 常见庭审顺序

| 阶段 | 主要内容 | 对陪审团的意义 |
| --- | --- | --- |
| 选任、宣誓与初步指示 | 组成陪审团，说明职责、程序和纪律 | 确立判断任务及信息边界 |
| 开案陈述（opening statements） | 双方介绍预期证据和案件主张；辩方是否及何时陈述依安排处理 | 提供理解线索，但陈述本身不是证据 |
| 检方举证 | 检方询问证人，辩方交叉询问，法院处理证据异议 | 检验指控是否有证据支持 |
| 辩方举证（如果选择提出） | 辩方可提出证人、文件或其他证据，检方依法交叉询问 | 被告也可以选择不作证；不能把沉默本身当作有罪证据 |
| 必要的反驳及相关动议 | 法院决定是否接纳适当反驳证据，处理证据不足动议等 | 控制案件进入裁决的法律基础 |
| 结案辩论（closing arguments） | 通常为检方、辩方、检方反驳 | 双方解释已经提出的证据；律师论辩仍不是证据 |
| 最终法律指示 | 说明构成要件、证明标准、相关抗辩、评议和裁决方法 | 给陪审团一套有法律约束的判断标准 |
| 私人评议及公开宣告裁决 | 陪审团讨论，必要时向法院提问，最终在法庭宣告裁决 | 将个别判断转化为依法作出的集体裁决 |

法官可以在结案辩论之前、之后或前后分别作出指示，不能把上表理解为所有法院唯一允许的顺序。[Rules 29、29.1、30、31][R03]；[审判陪审员手册][R13]

法律指示也有双方参与和保留异议的程序：双方可书面提出所请求的指示；法院须在结案辩论前告知其拟如何处理这些请求；对已给出或遗漏的指示，原则上须在陪审团退庭评议前具体提出异议及理由。未依 Rule 30 保留异议，会限制上诉审查，但仍有 Rule 52(b) 规定的明显错误审查空间。[Rule 30][R03]

### 8.3 证据门槛与证明力应当区分

法官通常决定某项证据能否进入庭审、能在什么用途上使用；陪审团评估已经依法接纳的证据是否可信、有多大分量。

例如，法官允许一份文件作为证据，不表示已经认定其内容真实可靠；反过来，某项材料被排除后，陪审员不能因为自己觉得重要，就继续将它作为裁决依据。[FRE 104、105、403][R04]；[审判陪审员手册的证据说明][R13]

### 8.4 信息隔离的目的

陪审员应依个案指示，避免私下调查、搜索网络、阅读案件报道、与外人讨论或通过社交媒体交换案件意见。日常生活经验可以帮助理解证据，私自补充未经庭审检验的具体事实则是另一回事。

其程序理由是：双方应当有机会知道并回应决定案件的证据。陪审员自行找到的信息没有经过同样的真实性审查、对质和法律争议处理。第九巡回区示范指示 6.20 对这些限制及理由作出了具体说明；实际案件应以审判法官给出的指示为准。[第九巡回区 2026 年 3 月版示范指示 6.20][R14]

## 9. 陪审团怎样认定事实与适用证明标准

### 9.1 无罪推定不是一种需要被告先证明的事实

被告开始受审时受到无罪推定保护。起诉、被告身份、选择不作证，都不代替检方对犯罪构成要件的证明。

检方必须证明构成所指控犯罪的必要要件。只要必要要件未被排除合理怀疑地证明，就不能就该罪定罪。特定积极抗辩可能具有另行规定的证明责任，不能因此把一般犯罪证明责任倒置。[Winship, 397 U.S. 358, 364][C08]；[第九巡回区示范指示 6.2—6.4][R14]

### 9.2 排除合理怀疑不是固定百分比

它高于民事案件常见的优势证据标准，但通常不以“95%”“99%”等数字定义。

第九巡回区示范指示 6.5 的主要含义是：证据应使陪审员确信被告有罪；合理怀疑应基于理性与常识，可以源于已有证据，也可以源于证据缺失；法律并不要求排除一切想象得到的怀疑。这是特定巡回区的示范表述，不是全国逐字统一的定义。[示范指示 6.5][R14]

因此，“我猜大概率是他干的”和“所有必要犯罪要件均已排除合理怀疑地成立”，是不同的判断。

### 9.3 多个罪项和多名被告必须分别判断

同一庭审可以包含多个罪项或多名被告。对甲罪的证据不能自动填补乙罪缺失的要件，对一人的有罪判断也不能替代对另一人的独立判断。

Rule 31 允许陪审团对已达成一致的被告或罪项先作部分裁决，并对未能一致的部分另行处理。[Rule 31(b)][R03]

### 9.4 对要件一致，不等于对所有细节都必须一致

陪审员必须对有罪裁决及法律要求的犯罪要件达成一致；但同一要件可能存在不同证明方式、实施手段或证据解释。是否必须就某个具体行为、事实选项进一步一致，取决于罪名结构、案件证据及适用判例。

因此，不能笼统地说“只要最后都认为有罪就可以”，也不能笼统地说“所有陪审员必须相信完全相同的故事”。在适当案件中，需要特别一致性指示。[第九巡回区示范指示 6.27 及其判例说明][R14]

<a id="s10"></a>
## 10. 评议、一致裁决与僵局

### 10.1 评议如何组织

陪审团退入非公开的评议环境，依照法官指示讨论证据与法律。陪审团主席（foreperson）负责组织讨论、与法院沟通或填写裁决文件等，其产生方法可能因地区或个案而异。

主席的角色不赋予其更高票权，也不意味着由主席替大家决定。每位陪审员都应独立判断，认真听取他人意见；被说服后可以改变观点，但不应仅为结束讨论而放弃诚实判断。[审判陪审员手册的 In the Jury Room 部分][R13]

法律并未规定所有案件都采用某一种首轮投票、固定讨论顺序或必须评议若干小时的统一算法。具体管理与指示应结合案件处理。

### 10.2 一致裁决的要求

Rule 31(a) 要求裁决一致并在公开法庭向法官作出。这不是多数决：11 人认为有罪、1 人认为无罪，不能成为有罪裁决；反向的 11 比 1 也不能成为无罪裁决。

裁决公布后、陪审团解散前，任一方可以要求法院逐一询问陪审员是否认同裁决，即 jury polling；法院也可主动进行。若核对后发现不一致，法院可要求继续评议，或宣布审判无效并解散陪审团。[Rule 31(a)、(d)][R03]

### 10.3 为什么会出现 hung jury

当陪审员经过评议仍无法对某个罪项达成一致时，即可能形成僵局（hung jury）。法院会判断是否仍有继续讨论的可能，必要时依法给出补充指示。

这类促成继续评议的指示常与 *Allen charge* 相关。其措辞和使用限制受适用判例约束，不能以逼迫某位陪审员放弃真实判断为代价要求一致。不同巡回区的处理可能不同。[第九巡回区示范指示 6.25—6.26 及其评注][R14]

若无法达成一致，法院可以对有关罪项宣布审判无效（mistrial）。检方可以对未能达成裁决的罪项重新审判；已经有效作出无罪裁决的其他罪项，应分别看待。[Rule 31(b)][R03]

### 10.4 一致规则的收益与代价

**制度分析：** 一致规则使少数意见不能被简单以多数票压过，要求陪审团认真回应仍然存在的疑点；同时，它也可能导致僵局、重复审判与较高成本。讨论压力还可能使个别成员勉强随多数，因此，保护独立判断与避免胁迫的要求必须同时存在。

“必须一致”是一项决定规则，并不能单凭自身保证评议充分或事实结论正确。

<a id="s11"></a>
## 11. 裁决后的控制、救济与量刑

### 11.1 有罪与无罪的终局性不对称

| 结果或问题 | 主要法律后果 |
| --- | --- |
| 陪审团作出有效无罪裁决 | 同一主权机关原则上不得就同一犯罪再次审判，以纠正其认为陪审团犯下的事实或法律错误 |
| 陪审团作出有罪裁决 | 被告可依适用规则提出裁决后动议及上诉 |
| 无裁决、形成僵局 | 可以宣布审判无效，未一致的罪项可以重新审判 |
| 定罪因程序错误被撤销 | 在适用规则下可能重新审判；并非所有撤销都等同于无罪 |
| 证据不足以支持定罪 | 适用无罪判决及不得重复追诉的相应保障，不能简单当作让检方补证重来的一般程序错误 |

核心依据：[第五修正案][R02]；[Rules 29、31、33][R03]；[McElrath][R22]；[Burks v. United States, 437 U.S. 1 (1978)][C23]。

这里讨论的是同一主权的重复追诉保障，不能进一步推导为“同一行为在一切州与联邦法律下永远只能被追诉一次”。

### 11.2 法官可以纠正什么

Rule 29 要求法院在证据不足以支持定罪时作出无罪判决，且允许在有罪裁决后撤销该裁决并作出无罪判决。

Rule 33 则允许法院依被告动议，为司法公正撤销判决并准予新审判。上诉法院还可以审查法律指示、证据裁定及其他依法提出的问题。[Rules 29、33][R03]

证据充分性审查不是让上诉法官重新自由选择自己更相信的证人。*Jackson* 的核心标准是：以有利于控方的方式看待证据后，是否仍有任何理性的事实裁判者能够排除合理怀疑地认定必要犯罪要件成立。[Jackson, 443 U.S. 307, 319][C19]

所以，陪审团的事实判断受到尊重，但有罪裁决并不是完全不可审查。

### 11.3 裁决后为何不能随意追问陪审员“当时怎么想”

FRE 606(b) 原则上禁止用陪审员证言或其陈述，探查评议中的言行、某因素对投票的影响及心理过程，以质疑裁决或起诉决定的效力。规则列明的例外包括：

1. 外部有害信息是否不当进入陪审团；
2. 外界影响是否不当作用于陪审员；
3. 将裁决填写进裁决表时是否发生错误。

这不是对所有评议问题的实体免责，而是对可用于攻击裁决的证据设置限制。[FRE 606(b)][R04]

*Peña-Rodriguez* 又确立一项重要宪法边界：有明确陈述表明某陪审员以种族刻板印象或种族敌意定罪，且该偏见是其投票的重要动因时，保护公正陪审团的要求可能迫使法院突破通常的评议证言排除规则。一般性抱怨或任何不当言论并不自动达到这一门槛。[Peña-Rodriguez, 580 U.S. 206 (2017)][R23]

### 11.4 “陪审团定罪，法官量刑”只是起点

普通联邦刑事案件通常由法官在定罪后量刑。但某些事实会提高被告依法面临的处罚范围，不能仅靠称其为“量刑因素”就交由法官自由认定：

- *Apprendi*：除狭窄的既往定罪事实例外等情形外，提高法定最高刑的事实须交陪审团排除合理怀疑地认定。
- *Booker*：联邦强制性量刑指南因相关事实认定方式引发第六修正案问题；补救方案使指南改为咨询性，而非法院可以完全无视的材料。
- *Alleyne*：提高强制最低刑的事实，同样属于必须交陪审团认定的事实。
- *Erlinger*：对于《武装惯犯法》中的既往犯罪是否发生在不同场合，须由陪审团一致、排除合理怀疑地认定；不能把它整体塞进既往定罪事实的狭窄例外。

被告有效承认有关事实或有效放弃相关权利等情况，需要另行考虑。上述原则也不表示法官在法律允许的刑罚范围内选择刑期时，所有相关事实都必须重新交陪审团。[Apprendi v. New Jersey, 530 U.S. 466 (2000)][C14]；[United States v. Booker, 543 U.S. 220 (2005)][C15]；[Alleyne v. United States, 570 U.S. 99 (2013)][C16]；[Erlinger v. United States, 602 U.S. 821 (2024)][R21]

### 11.5 联邦死刑的特别结构

18 U.S.C. § 3593 设置独立量刑听证，通常由定罪陪审团进行，也规定另组陪审团或在特定条件下由法院单独听证的路径。

检方证明加重因素须达到排除合理怀疑；加重因素认定必须一致。减轻因素由被告以信息的优势（preponderance of the information）证明，且一名或多名陪审员发现减轻因素，即可由认可该因素的陪审员纳入考虑，不要求其他人一致同意。建议判处死刑也须一致表决。这体现了死刑程序对加重与减轻的不同处理。[18 U.S.C. § 3593(b)—(e)][R06]

因此，“陪审团绝不参与刑罚决定”不符合联邦制度。

<a id="s12"></a>
## 12. 陪审团否决与独立性的边界

陪审团否决（jury nullification）通常指：陪审团即使相信法律上的定罪条件已经满足，仍因认为法律或其适用不公，而选择无罪。

理解这一现象，应分开三个层面：

1. **现实能力。** 陪审团可以作出无罪裁决，而无罪终局性通常阻止国家为纠正该结果再审。
2. **法律义务。** 联邦陪审员应依照法院提供的法律和证据裁判；*Sparf* 不承认陪审员可以把自行决定法律作为一般审判职责。
3. **程序权利。** 不能从现实能力直接推出被告有权要求法院指示“你们可以不遵守法律”。

依据：[Sparf, 156 U.S. 51 (1895)][C01]；[McElrath, 601 U.S. 87 (2024)][R22]。

**制度分析：** 否决可能被理解为抵制不公追诉的一道事实屏障，也可能被偏见利用，使受害人得不到依法裁判。其价值不能只凭“公民反抗国家”的抽象形象评价。现行制度同时保留无罪终局性和依法裁判义务，正体现了这种张力。

## 13. 历史演变与关键判例

### 13.1 英国来源：从地方知识与控告走向独立判断

美国陪审制度承袭英国普通法传统。早期陪审机构的调查、控告和地方知识功能，与现代中立听取控辩证据的审判陪审团并不相同。大陪审团与审判陪审团的职能、保密性及独立性经过长期演变，不能把现代整套程序归因于某一份中世纪文书的一次创制。[大陪审员手册的历史部分][R12]

在美国革命前，殖民地居民将陪审团视为抵御殖民政府滥权的重要工具。是否能够由本地公民参与司法，以及统治机关能否绕开陪审团，成为重要政治争议。[联邦司法中心的历史综述][R08]

### 13.2 1787—1791：从原始宪法到权利法案

1787 年宪法明确规定刑事审判陪审团，但未同时完整规定大陪审团起诉和民事陪审团保障。围绕新联邦司法权是否过强的疑虑，推动了后来的权利保障。

1791 年生效的第五、第六、第七修正案，分别强化起诉审查、刑事审判与民事陪审团保障。其制度地位因此超出了普通行政安排：不能因为某种程序更高效，就在普通立法或办案便利的层面任意取消宪法权利。[宪法与权利法案原文][R01]；[联邦司法中心历史综述][R08]

### 13.3 19 世纪：法官与陪审团权限逐步定型

早期美国曾存在陪审团能否同时判断法律与事实的争论。联邦实践逐渐明确由法官提供法律、由陪审团依该法律评价证据并形成裁决。

1895 年 *Sparf* 是这一界限的重要判例。同时，公民参与司法的理想长期与排斥女性、少数族裔及特定经济群体的现实并存。制度后来的“民主化”不能仅从建国时的宪法语言推断为早已完成。[Sparf][C01]；[Ballard][C04]；[Thiel][C05]；[Batson 对种族排斥历史的回顾][C12]

大陪审团的历史变化则有另一条线索：早期除审查检方指控外，还会主动提出控告（presentment），并对公共事务发表报告或提出请求。随着专业追诉机关的发展，主动控告实践逐渐式微，现代联邦大陪审团更集中于检察官组织的刑事调查与起诉审查。调查权限的保留，与更广泛公共监督角色的收缩，并行发生。[联邦司法中心历史综述的 Grand Jury Presentment and Investigatory Powers 部分][R08]

### 13.6 历史变化的三条主线

**制度分析：** 第一，陪审团从殖民时代的重要政治保障，成为有统一程序和职业司法配合的常设宪法机制；第二，公民参与逐渐从有限群体的资格，发展为反歧视与公平代表性的权利；第三，陪审团对刑罚正当性的控制，逐渐覆盖某些曾被归入“量刑”的关键事实。

这些变化并非单向扩大陪审团权限。专业化、认罪协商和案件处理成本，也使其在实际结案中的直接使用范围受到压缩。

## 14. 现实运行中的张力与制度代价

### 14.1 宪法地位很高，但多数案件不会进入陪审团审判

联邦量刑委员会 2025 财年统计收录了 **66,662 起个人量刑案件**，其中 **65,099 起（97.7%）**通过认罪处理，**1,563 起（2.3%）**来自审判。[2025 Sourcebook，Table 11、Table 12][R16]

这个数字必须带着口径使用：

- 数据涵盖该委员会收到资料的联邦重罪及 A 类轻罪个人量刑事件，财政年度为 2024-10-01 至 2025-09-30。
- 统计单位不是全部立案、全部被调查人或全部刑事程序。
- 无罪案件通常不会成为此类有罪量刑样本。
- “trial”包括审判路径，不能直接当作“陪审团审判”的独立占比。

依据：[Sourcebook 的 Introduction 与 Datafiles][R15]及[统计表原文][R16]。

认罪协商并没有在法律上取消陪审团权，但使实际事实裁判大量转向被告的有效承认和法院的认罪审查。[Rule 11][R03]

**制度分析：** 即使案件最终不进入陪审团审判，双方对可能的陪审团裁决、举证困难、审判成本及刑罚风险的判断，仍会影响协商。因此，“实际发生次数少”与“没有制度影响”不能直接画等号。

### 14.2 代表性与实际服务负担

随机名册能够限制人为挑选，但不能自动消除地址失效、名册覆盖差异、语言门槛、经济困难或照护负担的影响。分析代表性时，应分别观察来源覆盖、资格排除、免除延期、到庭与个案排除各环节。

这是根据选任流程与服务条件作出的分析框架，不是本文已经量化证明某司法区存在违法代表不足。[28 U.S.C. §§ 1863—1867][R05]；[服务费及雇主支付说明][R11]

### 14.3 普通判断能力与复杂证据

陪审团将社会经验带入事实认定，但金融、数字取证、统计及专业医学证据可能超出普通经验。制度通过专家证据、法官的证据把关和法律指示提供支持。

这些安排不能消除所有理解风险。要评价实际效果，需要观察特定证据如何呈现、指示是否清楚，以及是否存在误导性表述，不能只用“普通人不专业”或“多人讨论必然正确”代替研究。[FRE 403、702][R04]

### 14.4 大陪审团独立性与信息依赖

大陪审团依法可以拒绝起诉，且独立评议、投票；但其证据通常由检方组织，也不进行完整控辩对抗。独立表决与信息依赖可以同时存在。

因此，“大陪审团必然能阻止不当起诉”和“大陪审团只是没有任何作用的形式”都是超出本文资料能够证明范围的概括。[Rule 6][R03]；[United States v. Williams][C18]

### 14.5 评议保密与追责

保护评议有利于坦率交流和裁决稳定，却可能增加发现内部偏见的难度；无限开放评议又可能造成骚扰、反复争议及对陪审员的压力。

FRE 606(b) 的有限例外和 *Peña-Rodriguez* 的宪法例外，体现了在这些目标之间划界的方式。[FRE 606(b)][R04]；[Peña-Rodriguez][R23]

## 15. 与联邦民事陪审团及州制度的比较

### 15.1 联邦刑事与联邦民事

| 项目 | 联邦刑事审判陪审团 | 联邦民事审判陪审团 |
| --- | --- | --- |
| 主要宪法依据 | 第三条、第六修正案等 | 第七修正案等 |
| 是否所有案件都适用 | 有轻微违法等边界，也可依规则放弃 | 需判断法律性质、请求的救济等，并非一切民事案件都有陪审团权 |
| 典型证明标准 | 犯罪要件须排除合理怀疑 | 通常为优势证据，特定问题可能采用其他标准 |
| 人数 | 原则上 12 人，Rule 23 规定例外 | Rule 48 原则上从至少 6 人、不超过 12 人开始，除非约定，否则至少 6 人参加裁决 |
| 裁决票数 | 必须一致 | 原则上一致，但当事人可以另作约定 |
| 是否使用大陪审团起诉 | 特定刑事案件涉及 | 普通民事诉讼不适用这一刑事起诉机制 |
| 未依法及时提出请求的后果 | 不宜套用民事请求期限分析 | Rule 38 对陪审团请求及放弃规定专门要求 |

依据：[权利法案][R02]、[刑事 Rule 23、31][R03]、[民事 Rule 48][R27]、[民事 Rule 38][R28]、[联邦法院两类案件证明标准说明][R26]。

### 15.2 联邦与州

美国存在联邦与州各自的刑事司法系统。州法院不是联邦地区法院的下级法院；州的陪审团组织和程序不能直接作为联邦规则的证据。

一些联邦宪法保障已通过第十四修正案适用于州，例如严重犯罪的陪审团审判权和一致定罪要求；第五修正案的大陪审团起诉要求则没有以相同方式强制各州采用。[Duncan][C06]、[Ramos][R20]、[Hurtado v. California, 110 U.S. 516 (1884)][C20]

因此，看到某州使用不同人数、选任方法或起诉机制时，需要先判断它属于州法允许的差异，还是触及适用于州的联邦宪法最低标准。更不能把某州的具体规则推广为全美统一规则。

## 16. 示例与常见误解

### 16.1 一个简化的联邦刑事案件

假设联邦检方拟以一个最高可判超过一年监禁的非死刑犯罪起诉甲：

1. 在没有依法放弃大陪审团起诉的情况下，案件提交大陪审团。23 名成员中有 12 人同意起诉，满足最低赞成票数；这并未证明甲有罪。
2. 甲不认罪，案件进入陪审团审判。法院依法抽取并询问候选人，组成 12 人陪审团并选任替补。
3. 检方必须在庭审中证明每个必要犯罪要件。甲可以质疑证据，也可以不提出自己的证人；不作证本身不能填补检方的证明不足。
4. 如果 12 人一致认为检方证明成立，可以作出有罪裁决；如果 12 人一致认定检方未达到标准，应作无罪裁决。
5. 如果 11 人主张有罪、1 人保有合理怀疑，尚不能作出有罪裁决；若最终僵局，可以宣布该罪项审判无效并依法重审，而不是自动无罪。
6. 如果作出有效无罪裁决，检方不能仅因认为陪审团错误，就就同一犯罪在同一主权下再审。
7. 如果作出有罪裁决，甲仍可依法提出裁决后动议及上诉；通常由法官量刑，但提高法定处罚范围的某些事实须遵守陪审团认定要求。

本例仅用于展示已述规则的衔接，不对应真实案件，也没有涵盖全部审前、证据和救济问题。

### 16.2 常见误解速查

| 误解 | 更准确的表述 |
| --- | --- |
| 大陪审团是审判陪审团的上级 | 两者负责不同阶段，彼此不是上诉关系 |
| 被大陪审团起诉就说明已经有罪 | 只是达到起诉门槛，定罪须另外证明 |
| 美国刑事陪审团一律 12 人且不能变化 | 联邦原则为 12 人，存在 Rule 23 的例外；州制另须核对 |
| 联邦陪审团采取多数决 | 刑事审判裁决必须一致 |
| 一人不同意有罪就等于已经判无罪 | 可能形成僵局；无罪裁决本身也须一致 |
| “同侪”要求陪审员与被告身份相同 | 法律保障公正选任和公平来源，不保证身份相同或人口配额 |
| 律师有权任意挑选想要的人 | 随机来源、法官控制、排除名额及反歧视规则共同约束选任 |
| 陪审团可以依法自由忽略法律 | 联邦陪审员有遵守法律指示的义务；事实上的否决能力应另行理解 |
| 法官无法纠正有罪裁决 | 有证据不足动议、新审判动议及上诉等控制机制 |
| 陪审团从不参与量刑 | 特定增加刑罚的事实及死刑程序构成重要例外 |
| 大陪审团保密意味着所有证人都自动负有同一保密义务 | Rule 6(e) 列明义务主体，证人须另行分析 |
| 认罪率可以直接等同于全部案件的陪审团使用率 | 必须核对样本、统计单位、案件范围及审判类型 |

## 17. 术语表与资料使用方法

### 17.1 术语表

| 英文 | 本文用语 | 说明 |
| --- | --- | --- |
| grand jury | 大陪审团 | 调查及起诉审查机构 |
| petit jury / trial jury | 审判陪审团 | 决定刑事有罪与否，或民事责任的陪审团 |
| indictment | 大陪审团起诉书 | 经大陪审团同意提出的正式指控文件 |
| information | 检察官起诉书 | 法律允许时由检察官提出的指控文件；并非这里通常意义上的“信息” |
| probable cause | 相当理由 | 本文用于解释大陪审团起诉门槛，不等同于有罪证明标准 |
| venire / panel | 候选陪审员群体 | 进入个案选任的候选人员；具体语境中用法可能略有不同 |
| voir dire | 候选陪审员询问 | 用于判断资格、偏见及是否适合审理本案 |
| challenge for cause | 有因排除 | 基于法定适当理由申请排除候选人 |
| peremptory challenge | 无因排除 | 不须先达到有因排除标准，但有名额且受反歧视限制 |
| alternate juror | 替补陪审员 | 依法准备替换不能履职正式成员的陪审员 |
| jury instructions | 陪审团法律指示 | 法官提供的判断标准和程序要求 |
| deliberations | 评议 | 陪审团围绕证据和法律进行的内部讨论 |
| verdict | 裁决 | 陪审团对提交问题作出的决定；与法院最终判决并非同一概念 |
| acquittal | 无罪判决／无罪裁决 | 由法院或陪审团依相应程序作出，须结合语境区分 |
| hung jury | 陪审团僵局 | 无法达成所需一致意见 |
| mistrial | 审判无效 | 本轮审判因僵局或其他原因中止，相关指控未形成通常的终局裁决；是否可重审须另行分析 |
| jury polling | 逐一核对裁决 | 法院逐个询问陪审员是否认同已宣布的裁决 |
| jury nullification | 陪审团否决 | 陪审团违背依法定罪结论而选择无罪的现象 |

### 17.2 阅读与复核建议

对运行机制，先阅读第 1、5—11 节，并直接核对 Rules 6、7、11、23、24、29、30、31、33。对设计原则，结合第 3、12、14 节阅读，不宜将分析性解释误作条文原话。对历史变革，按第 13 节时间线回查具体判例。

原始资料分三组使用：

- **法律及规则**用于确认权限、门槛、条件和法律后果。
- **原始判例**用于确认争议问题、法院实际裁判及其适用范围，区分法院意见、个别大法官意见与不属于判决正文的提要。
- **法院手册、司法中心历史研究和官方统计**用于解释运作、背景与实际规模；它们不能代替法律规则，也不能使某个地区的做法自动成为全国规范。
